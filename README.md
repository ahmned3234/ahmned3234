### 🌾 Bilingual Agricultural Monitoring & RAG Advisory System

**Graduation Project — AI / Backend Engineer**

An IoT-integrated bilingual agricultural advisory system that combines real-time farm sensor data with a curated knowledge base to generate grounded recommendations in Arabic and English.

**My contribution:** Designed and implemented the AI/RAG module end-to-end, including multilingual document processing, vector retrieval with PostgreSQL/pgvector, HNSW optimization, LLM integration, confidence gating, sensor-grounded generation, and FastAPI integration.
